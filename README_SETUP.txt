FIXZY — KERANGKA PEMBUKUAN SERVIS & PENJUALAN

1. Buat Google Spreadsheet baru khusus FIXZY.
2. Buka Extensions > Apps Script, tempel Code.gs.
3. Isi SPREADSHEET_ID dengan ID Spreadsheet baru.
4. Jalankan setupFixzy() satu kali dari editor Apps Script.
5. Deploy sebagai Web App, lalu salin URL /exec ke config.js.
6. Upload index.html, app.js, style.css, config.js ke hosting HTTPS.
7. Tes dahulu dengan data contoh.

PENTING: Kerangka ini belum mempunyai login dan pembatasan hak akses server-side yang siap produksi. Jangan gunakan untuk data keuangan nyata sebelum autentikasi/otorisasi ditambahkan dan diuji. Jangan gunakan Spreadsheet atau folder Drive TESPOIN.
